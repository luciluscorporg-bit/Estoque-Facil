ESTOQUE FÁCIL — VERSÃO 2
=========================

Arquivos: index.html, manifest.webmanifest, sw.js e este manual.

NOVIDADES v2.2
- Resultados parciais (sem nome) das bases abertas agora preenchem marca/quantidade/categoria/foto e pedem só o nome.
- UPCitemdb removido (bloqueado pelo navegador).
- Diagnóstico por fonte e links de pesquisa manual quando nada é achado.

NOVIDADES v2
- Campos para marca, fabricante, categoria e URL de foto.
- Busca ampliada: catálogo local, OSCBR V4 (token opcional), Open Food Facts, Open Products Facts, Open Beauty Facts, Open Pet Food Facts.
- Pesquisa local por nome, código, marca e categoria.
- Metadados incluídos em CSV/XLSX e backup JSON.
- Mantém o banco IndexedDB existente (mesmo nome do banco; atualização de versão do esquema).

FONTES E LIMITAÇÕES
1. OSCBR: integração V4 por GET https://gtin.rscsistemas.com.br/api/v4/gtin/{GTIN}. Exige token Bearer. Crie uma conta em https://gtin.rscsistemas.com.br/cadastro e consulte a documentação em https://gtin.rscsistemas.com.br/documentacao. O token pode ser informado na seção Fontes de pesquisa dentro do app; fica no armazenamento local do navegador, não no GitHub. Isso não é armazenamento seguro contra alguém com acesso ao aparelho/perfil. Para uso empresarial, implemente um backend/proxy com segredo no servidor. O plano deve liberar V4; caso contrário, será necessário V3 ou plano compatível.
2. UPCitemdb: removido na v2.2 (o navegador bloqueia a consulta por CORS).
3. Open Food Facts e as bases Open Products/Beauty/Pet Facts são colaborativas. Cobertura e disponibilidade variam.
4. ConsultaProdutos: a página oficial da API informa que endpoints e autenticação serão publicados na fase de produção. Não foi implementada uma chamada inventada. Use https://consultaprodutos.com.br/api para acompanhar a disponibilidade.
5. EAN-Search: não foi possível confirmar uma especificação pública atual de endpoint/API adequada para chamada automática no navegador. O site fica disponível como consulta complementar: https://www.ean-search.org/. Não há scraping.

ATUALIZAR NO GITHUB (CELULAR)
1. Faça um backup JSON no Estoque Fácil antes de atualizar.
2. Baixe e extraia o ZIP.
3. Abra seu repositório GitHub: https://github.com/luciluscorporg-bit/estoque-facil (confirme o nome se o seu repositório tiver outro).
4. Add file > Upload files.
5. Envie os arquivos extraídos para a raiz. Quando o GitHub perguntar, confirme a substituição de index.html, manifest.webmanifest e sw.js.
6. Commit changes. Não apague o repositório nem crie outro.
7. Aguarde o GitHub Pages publicar. Abra https://luciluscorporg-bit.github.io/estoque-facil/ e atualize a página.
8. Se a versão antiga persistir, feche a aba, abra novamente; se necessário limpe os dados/cache do site. O Service Worker tem cache com versão própria; para forçar atualização, remova dados do site no Chrome e recarregue.
9. Restaure o backup se os produtos não aparecerem. A atualização não deve apagar IndexedDB, mas o backup é a proteção.

DADOS E PRIVACIDADE
- Produtos, histórico e metadados ficam no IndexedDB do aparelho/navegador.
- Token OSCBR fica em localStorage deste navegador, nunca no arquivo do GitHub. Ainda assim, localStorage não é cofre de segredos.
- Fotos externas são exibidas por URL; não são copiadas para o aparelho. Se o endereço da imagem mudar ou ficar offline, a foto pode não aparecer.
- O catálogo cadastrado funciona offline; consultas externas exigem internet.
- O navegador pode bloquear APIs externas por CORS, limites ou indisponibilidade. O cadastro manual permanece disponível.
- Valide nomes, marca, fabricante e imagens antes de cadastrar. Não use NCM/CEST como orientação fiscal sem conferência profissional.
